# GestureFlow API

The backend of [GestureFlow](https://github.com/AtharvaM25/Hand_Recognition): hand-sign
recognition from landmarks, served with FastAPI. This Space is deployed automatically from
GitHub (`.github/workflows/deploy-api.yml`); don't edit files here, edit the repository.

Opening the Space shows the API docs (`/` redirects to `/docs`).
